# UX/UI Pro Design Skill

This skill provides strict enterprise design rules for crafting premium, high-converting minimal SaaS UIs.

- Rule 1: NO generic dark-teal or neon gradients. Use a minimal, high-contrast palette (e.g., pure white or #F8FAFC backgrounds, #0F172A for primary text).
- Rule 2: Use strict Tailwind spacing scales. Elements must have clear visual hierarchy.
- Rule 3: Use shadcn/ui minimal components. Borders should be subtle (e.g., border-border/40), and shadows should be soft (`shadow-sm`).
- Rule 4: Error states must be handled gracefully using a structured Alert component with a soft red background, not floating text.
